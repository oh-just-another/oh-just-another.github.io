# Рекомендации по сайту

Состояние после чистки 2026-07 и что ещё стоит сделать до/после публикации
ohjustanother.site.

## Сделано в чистке

- Webflow-экспорт заменён рукописной семантической разметкой
  (`header` / `main` / `footer`, настоящий `nav`); убраны webflow-атрибуты,
  иконочный шрифт, `webfont.js` и все ссылки на `cdn.prod.website-files.com`.
- Вместо старого normalize-блока — современный минимальный CSS-reset.
- Все тексты переписаны с нуля (прежние принадлежали другому сайту).
- Шрифты: системный моноширинный стек (`ui-monospace` → `Menlo`/`Consolas`) —
  ноль внешних запросов, mono-стиль сохраняется на любой ОС.
- Тёмная тема через `prefers-color-scheme`; цвета — в CSS-переменных.
- Мета: canonical, `theme-color`, единая og/twitter-карточка, локальные иконки.
- Логотип — инлайн-SVG с `fill="currentColor"`, цвет переключается темой через
  `--logo-ink` (светлая `#4e8cff`, тёмная `#fff`).

## Желательно

- **robots.txt + sitemap.xml** — для одностраничника тривиально, помогает индексации.
- **JSON-LD `Organization`** (name, url, logo, `sameAs: [github]`) — более богатая
  выдача в поиске.
- **Self-hosted шрифт**: если системный mono-стек окажется слишком разным между
  платформами — самостоятельно хостить один woff2-сабсет `Roboto Mono` (или
  `Geist Mono`) с `font-display: swap`; загрузчик Google Fonts / webfont.js не
  возвращать.
- **Заголовки безопасности/кеширования** на хостинге (GitHub Pages их не даёт;
  Cloudflare или Netlify — дают): `Cache-Control` для иконок,
  `X-Content-Type-Options: nosniff`.
- **Своя страница 404** в том же стиле («page count: 1 · this is not it»).
- **Доступность**: акцентный синий `#4e8cff` на белом — контраст ~3:1; для крупного
  дисплейного текста допустимо, но не использовать его для мелкого текста и ссылок.

## Keep it boring

Сайт — один статический HTML с инлайн-CSS и без JS. Так и оставить: без сборки,
без фреймворков, без аналитики, пока нет вопроса, на который она отвечает.
